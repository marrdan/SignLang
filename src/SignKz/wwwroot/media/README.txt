Put photos and videos of the signs in this folder.

Name each file like the sign id from Data/signs.json:
  Numbers:  1.jpg  2.jpg ... 10.jpg
  Letters:  a.png  b.png  c.jpg ... z.jpg   (26 English letters, lowercase)

Images: .jpg .jpeg .png .webp .gif      Videos: .mp4 .webm

You can also use links instead of files. Open Data/signs.json and fill "imageUrl" or "videoUrl"
with an https:// link (for example a YouTube link for videoUrl). Every sign already has both
fields, they are just empty.
Refresh the page after adding files. No restart is needed.
